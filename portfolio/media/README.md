# Mídia do portfólio

Este diretório é lido automaticamente pelo portfólio.

Arquivos esperados para o teste da Máquina de Lavar Cachorros:

- `prototipo-01.jpg` — imagem principal / capa;
- `montagem-01.jpg` — foto da montagem eletrônica;
- `teste-funcionamento.mp4` — vídeo curto de funcionamento.

Enquanto esses arquivos não existirem, o portfólio exibe placeholders de mídia sem quebrar a página.
